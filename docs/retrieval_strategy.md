# Retrieval Strategy

## Baseline: Cypher Queries
- 10+ query templates
- Deterministic retrieval
- Exact match filtering

## Embeddings
- Node embeddings using numerical features
- Feature vector embeddings using text descriptions
- Semantic similarity search
- Comparison of 2+ embedding models

## Hybrid Approach
- Combines Cypher and embedding results
- Deduplication and ranking
- Optimal context for LLM
