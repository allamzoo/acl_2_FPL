# System Architecture

## Overview
Document the overall system design, components, and interactions.

## Components
1. Input Preprocessing Layer
2. Graph Retrieval Layer
3. LLM Layer
4. UI Layer

## Data Flow
- User query → Preprocessing → Retrieval → LLM → Response

## Technologies Used
- Neo4j for graph database
- LangChain for LLM orchestration
- Streamlit for UI
- spaCy for NER
- Sentence Transformers for embeddings
